# Le Nexus

L'appli Android qui rassemble toutes mes applis.

- `applis.json` : la liste des applis affichées dans le Nexus (nom, description, dépôt GitHub des releases, logo ou emoji, couleur facultative).
- `icones/` : les logos des applis.

Modifier ces fichiers ici suffit : le Nexus se met à jour tout seul, sans recompiler (compter jusqu'à 5 minutes).
Attention : `applis.json` doit rester du JSON valide (guillemets doubles, une virgule entre chaque bloc, pas de virgule après le dernier).

Les APK du Nexus sont publiés dans les **Releases** de ce dépôt.
